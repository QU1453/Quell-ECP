# Quell-ECP

模拟跨境电商平台（自营单店铺 B2C），用于业务流程模拟与学习演示，可自托管部署到自租服务器。

## 项目状态

需求与架构方案已确定，代码尚未开始搭建（见里程碑计划）。

- [产品需求文档 (PRD)](docs/PRD.md)
- [技术架构方案](docs/ARCHITECTURE.md)

## 技术栈概览

React + Vite（前台商城 + 运营后台）· NestJS + Prisma · PostgreSQL · Docker Compose 部署

## 计划里程碑
